# Student Management System

A React and JavaScript app for viewing and managing student records. This project was created for the DIWA2110 Web Application Development assignment.

## Features

- View student ID, name, age, email, course, and enrollment status.
- Add and edit student records using a form modal.
- Confirm before deleting a student.
- Validate required fields, age, and email.
- Update the table using React state without refreshing the page.
- Use a responsive layout for smaller screens.
